# Тестовое задание для ФГУП НИИ Квант

Cервис на Go, предоставляющий данные о пользователях из внешнего API (JSONPlaceholder) с поддержкой кэширования, дедупликации запросов, ограничения конкурентности и корректного завершения работы.
## Стек технологий
- **Язык**: Go (1.26+)
- **HTTP-фреймворк**: Fiber v3
- **Архитектура**: Clean Architecture (Domain -> UseCase -> Adapters)
- **Контейнеризация**: Docker, Docker Compose

## Ключевые возможности
- **Эндпоинты `GET /users` и `GET /users/{id}`**: Получение списка и конкретного пользователя
- Сервис трансформирует структуру внешнего API, отсекает лишние поля и преобразует сложные вложенные объекты ('address', 'company') во плоскую модель данных
- Данные кэшируются на 1 минуту. Реализована защита от гонок данных на базе 'sync.RWMutex' и фоновый уборщик (janitor) для очистки устаревших записей
- **Логирование**: Встроено Middleware-логирование входящих HTTP-запросов (метод, путь, статус-код, время обработки)
- **Таймауты**
- **Запуск через Docker Compose**

### Дополнительные возможности
- **Ограничение одновременных запросов**
- **Дедупликация запросов**
- **Покрытие тестами**: Написаны юнит-тесты на ключевые сценарии UseCase
- **Graceful Shutdown**: Сервер корректно перехватывает системные сигналы ('SIGINT', 'SIGTERM')

## Важное примечание!
В ходе работы было замечено, что сервис JSONPlaceholder при отправке на него более +- 5 подряд запросах может временно блокировать передачу данных.
Для решения проблемы были использованы следующие способы оптимизации:
- Исходящие запросы маскируются под стандартный браузер
- Реализован слив Body ответа (`io.Copy(io.Discard, resp.Body)`)
